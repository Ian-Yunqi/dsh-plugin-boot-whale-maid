两种验收模式

模式 1 · 独立动作预览（默认，现在就是）

直接双击本文件（file://）即自动播放，用 SVG 占位图形播放完整时间线。

本模式不发任何图片请求：占位图形以 data: URI 内联，绝不复制、也绝不重新托管原包素材。 需要浏览器允许以 file:// 读取同目录脚本；若被策略拦下，请用任意本地静态服务器打开本文件 （静态服务器只提供本页与 lib/client.js，它不会让 /boot-assets/whale-maid/ 存在）。

模式 2 · 真实素材验收

只有在真正提供该素材路由的同源环境里才有意义，例如已安装并启用 maid-atelier 皮肤插件的 DSH： 打开 http://127.0.0.1:19387/boot-assets/whale-maid/<hash>.png 应返回图片。

普通静态服务器不等于素材路由存在。仅当路由返回 404 时，动画进入 ≤1s 的降级幕 —— 这是预期分支，不是错误。

页面内可核对的验收点

  • 时间线：0.0 起幕 / 0.5 开幕布 / 1.8 主立绘 / 2.05 右 Q 版 / 3.2 标题 / 4.4 光点·鲸尾 / 5.6 渐出 / 6.4 结束。
  • 跳过：画面出现后，点击任意位置或按 Esc 都在 150ms 内退场（与正式客户端同一套逻辑）。
  • 隔离：舞台全部在 .dsh-whale-maid-boot-host 的 shadow root 内，本页样式不受影响。
