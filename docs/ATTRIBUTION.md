# 素材来源与署名

## 本版生成素材

主立绘和深海宫殿由内置 imagegen 工具根据本次对话中认可的御姐参考图生成。主立绘随后按用户提供的新参考图调整脸部和服饰，采用白色长裙、低饱和深靛蓝垂袖和银色冰蓝饰件；保留银灰发与站立构图。用户提供参考图的来源与授权未在本对话中确认，本地衍生设计不构成对参考图或相关角色的独占权利声明。生成 PNG 随包携带，未用原皮肤立绘文件替代。生成不代表宣称独占所有角色概念或元素。
