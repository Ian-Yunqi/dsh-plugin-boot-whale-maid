# 美术与动作

- 主体：银灰长发，按用户最新参考调整纤长脸部轮廓、冷静的蓝眼和收敛的表情；保留成熟御姐方向。
- 衣料：参考白色挂颈贴身上衣、露肩和垂落袖披、流动长裙。袖披采用低饱和蓝紫调深靛蓝，白色为裙装主体，银色和冰蓝晶体点缀；减少金色刺绣和繁复荷叶边。参考图的背景、碎片、坐姿和兔耳没有作为开场素材复制。
- 小人物：使用原来的蓝发卡通 Q 版，不换成银灰发版本。
- 背景：独立生成的深海宫殿底图，鲸鱼与水下光，没有烘焙文字或人物。
- 主体和标题分层，Q 版层级 6 高于宫殿 1。宽屏只显示一位主角。标题盒从实际 PNG 的宽高比计算，与主立绘至少保持 32px 间距，窄屏改为下方标题。
- 正常动画总长 9600ms，入场和幕布比原版放慢 1.5 倍；末尾 1200ms 渐出。减少动态效果时静态展示 2600ms，仍可随时跳过。

PNG 的 alpha 通道来自内置 imagegen，保留原始生成文件；没有用抠图脚本修改角色。包中两个生成 PNG 内容哈希与 manifest 一致。六个内部角色键映射到三幅实际素材，源数据见 assets.json。

加载修复：主立绘和背景为必需素材；原 Q 版为可选素材。Q 版通过插件路由读取本机已安装的原皮肤文件，原皮肤禁用不影响读取，缺失时只隐藏小人物。不会为恢复 Q 版强行启用原皮肤或覆盖用户壁纸。

0.2.3 配色调整：袖披回到深靛蓝，减少灰紫泛色；白裙改为柔和冷白和蓝灰褶皱阴影，收敛高光。脸、银灰发、服装款式和站姿保留。背景、原蓝发 Q 版和 9.6 秒节奏不变；继续保留 Q 版缺失只隐藏自身的加载修复。

0.2.4 名称调整：开场中文标题为“深度求索”，英文副标题为 DEEPSEEK；四个汉字沿用原逐字显现逻辑，完整动画节奏和配色不变。
